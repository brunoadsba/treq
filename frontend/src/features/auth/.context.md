# Feature: Authentication & Authorization (Frontend)

## Visão Geral
Esta feature gerencia o estado de autenticação do usuário, persistência de tokens JWT e proteção de rotas privadas.

## Arquitetura
```
auth/
├── api/
│   └── authSchemas.ts      # Validação Zod para login
├── components/
│   └── LoginForm.tsx      # Formulário de login premium (Hook Form + Zod)
└── .context.md            # Este arquivo
```

## Decisões Técnicas
1. **SSO Local (Mock)**: O login utiliza `/auth/login` (Backend) que retorna um JWT assinado.
2. **Persistência**: O token é armazenado no `localStorage` sob a chave `treq_token`.
3. **Redirecionamento**: 
   - Usuários não autenticados acessando `/chat` ou `/agent` são jogados para `/login`.
   - Após login bem-sucedido, o usuário é levado para `/chat`.
4. **Resiliência 401**: Adicionado interceptor lógico nos hooks de API. Qualquer resposta `401 Unauthorized` do backend dispara:
   - `localStorage.removeItem('treq_token')`
   - `router.push('/login?error=Session Expired')`

## Estética (UI/UX)
- Design minimalista seguindo a paleta Treq.
- Animações de loading no botão "Entrar".
- Feedback de erro visual para credenciais inválidas.

## LGPD e Segurança
- Tokens JWT expiram em 30 minutos (configurado no backend).
- O `user_id` é extraído apenas do token validado, nunca aceito via corpo da requisição em rotas protegidas.
