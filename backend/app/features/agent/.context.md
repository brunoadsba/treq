# Agent Feature - Treq Enterprise

## Visão Geral
Esta feature implementa o **Agente de Automação e Conhecimento** usando LangGraph para orquestração de agentes.

## Arquitetura
```
agent/
├── .context.md          # Este arquivo
├── state.py             # AgentState (TypedDict + Cognitive Fields)
├── schemas.py           # Pydantic Schemas (PlannerDecision, etc.)
├── graph.py             # StateGraph (Cognitive Routing)
├── nodes/               # Implementação dos nodes
│   ├── planner.py       # Cérebro: Planejamento ReAct via LLM
│   ├── retriever.py     # RAG: Busca técnica
│   ├── executor.py      # Mãos: Execução dinâmica (Slot Filling)
│   └── responder.py     # Voz: Síntese cognitiva de resposta
├── tools/               # Ferramentas registradas
└── prompts.py           # Prompts ReAct e Injeção de Contexto
```

## Decisões Arquiteturais
- **Brain Shift (L6+)**: Migração de heurística hardcoded para raciocínio dinâmico via LLM.
- **Protocolo ReAct**: Planner gera Thought -> Action -> Slot Filling em um único passo estruturado.
- **Transparência Operacional**: Campo `thought` propagado até a API para auditoria em tempo real.
- **Slot Filling & Review**: Extração dinâmica de parâmetros (summary, channel, etc.) com fase intermediária de revisão humana via modais interativos antes da execução final.
- **Cognitive Transparency (Manus 1.6)**: Exposição do raciocínio interno (`thought`) e rastro de execução (`trace`) em tempo real no frontend via SSE.
- **Isolamento Docker-Centric**: A execução do Agente é restrita a containers Docker para evitar falhas de segmentação e rede (IPv6/IPv4) inerentes ao WSL2.

## Dependências
- `langgraph>=0.0.15`
- `langchain>=0.1.0`
