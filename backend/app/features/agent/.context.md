# Agent Feature - Treq Enterprise

## Visão Geral
Esta feature implementa o **Agente de Automação e Conhecimento** usando LangGraph para orquestração de agentes.

## Arquitetura
```
agent/
├── __init__.py          # Exports públicos
├── state.py             # AgentState (TypedDict)
├── graph.py             # StateGraph com nodes e edges
├── nodes/               # Implementação dos nodes
│   ├── __init__.py
│   ├── planner.py       # Decide RAG vs Tool
│   ├── retriever.py     # Integra com RAGService
│   ├── executor.py      # Executa ferramentas
│   └── responder.py     # Gera resposta final
├── tools/               # Ferramentas disponíveis
│   ├── __init__.py
│   ├── base.py          # BaseTool interface
│   ├── registry.py      # SSOT: Registro central de intenções/tools
│   ├── jira.py          # Ferramenta Jira
│   └── slack.py         # Ferramenta Slack (integrada com Connectors)
├── prompts.py           # Prompts do sistema (Defensive RAG)
└── routes.py            # Endpoint /agent/chat
```

## Decisões Arquiteturais
- **Rota paralela**: `/agent/chat` separado de `/chat/` (MVP)
- **RLS propagado**: `user_id` passado no AgentState
- **Dynamic Tool Dispatching**: `registry.py` centraliza mapeamento de intenções para evitar drift entre Planner e Executor.
- **Mocks na Sprint 1**: Ferramentas simuladas para validação do grafo

## Dependências
- `langgraph>=0.0.15`
- `langchain>=0.1.0`
