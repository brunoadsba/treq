# Connectors Feature - Treq Enterprise

## Visão Geral
Feature para conectores com sistemas externos (Confluence, Slack, Jira).

## Arquitetura
```
connectors/
├── __init__.py
├── base.py              # BaseConnector interface
├── confluence/
│   ├── __init__.py
│   ├── client.py        # ConfluenceClient (mock/real)
│   ├── sync.py          # Sincronização de páginas
│   └── models.py        # Schemas Pydantic
├── slack/
│   ├── __init__.py
│   ├── client.py        # SlackClient (mock/real)
│   └── models.py        # Schemas Pydantic
└── routes.py            # Endpoints de gestão
```
