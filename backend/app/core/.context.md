# Segurança RLS - Contexto Técnico

## Visão Geral

O sistema implementa Row Level Security (RLS) em duas camadas:
1. **Supabase PostgreSQL** - Políticas nativas no banco
2. **Aplicação Python** - Filtro `_filter_by_rls()` no RAGService

## Fluxo de Segurança

```
┌─────────────────┐
│   Frontend      │ user_id no token/header
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   /agent/chat   │ Extrai user_id da request
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   AgentState    │ user_id propagado no estado
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  retriever_node │ Passa user_id para RAGService
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   RAGService    │ search_similar(user_id=...)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ _filter_by_rls  │ Filtra documentos por permissão
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│    Resultado    │ Apenas documentos permitidos
└─────────────────┘
```

## Regras de Acesso

| Classification | allowed_users | Quem Acessa |
|----------------|---------------|-------------|
| `public` | qualquer | Todos os usuários |
| `internal` | `["*"]` | Qualquer autenticado |
| `internal` | `["user_a"]` | Apenas user_a |
| `confidential` | `["admin"]` | Apenas admin |

## Metadados de Segurança

Cada chunk no Supabase possui:

```json
{
  "classification": "internal",
  "allowed_users": ["user_id_1", "user_id_2"],
  "department": "engenharia",
  "indexed_at": "2026-01-16T..."
}
```

## Políticas no Supabase

```sql
-- Bloqueia anônimos
CREATE POLICY "Anon cannot access" ON knowledge_base
FOR ALL USING (false);

-- Leitura filtrada
CREATE POLICY "users_read_allowed_docs" ON knowledge_base
FOR SELECT USING (
  metadata->>'classification' = 'public' OR
  metadata->'allowed_users' ? '*'
);

-- Backend tem acesso total
CREATE POLICY "service_role_full_access" ON knowledge_base
FOR ALL USING (auth.role() = 'service_role');
```

## Código de Filtro

```python
def _filter_by_rls(self, documents, user_id):
    filtered = []
    for doc in documents:
        metadata = doc.get('metadata', {})
        classification = metadata.get('classification', 'internal')
        allowed_users = metadata.get('allowed_users', ['*'])
        
        if classification == 'public':
            filtered.append(doc)
        elif '*' in allowed_users:
            filtered.append(doc)
        elif user_id in allowed_users:
            filtered.append(doc)
    
    return filtered
```
